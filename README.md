# Portfolio — Channa Ashari Alfaroek

Website portofolio akademik mahasiswa Teknik Komputer, Politeknik Negeri Samarinda.

## Cara menjalankan
1. Ekstrak file ZIP.
2. Buka `index.html` di browser untuk melihat website.

## Cara memasang di GitHub Pages
1. Login ke GitHub dan buat repository baru, misalnya `portfolio`.
2. Pilih **Public** dan buat repository.
3. Upload `index.html` dan `README.md` ke repository (langsung di halaman repository: **Add file → Upload files**).
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main`, folder `/(root)`, lalu klik **Save**.
7. Tunggu proses publikasi. GitHub akan menampilkan alamat website pada bagian Pages.

## Catatan
- NIM sengaja tidak ditampilkan pada website publik.
- Tombol GitHub pada bagian kontak masih mengarah ke halaman utama GitHub. Ganti dengan URL profil GitHub milikmu setelah akun tersedia.
- Isi proyek mengikuti dokumen portofolio yang diberikan. Tambahkan foto, screenshot proyek, dan tautan repository proyek jika sudah siap.
